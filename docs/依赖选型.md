## 2. 各依赖选型理由

### 2.1 uView UI 2（UI 组件库）

**选用原因：**

- 专为 uni-app Vue2 设计，组件丰富（Button、Switch、Tabs、Popup、Form 等）
- 与原型图高度匹配：圆角卡片、渐变按钮、Segmented Control、列表项
- 内置 `rpx` 适配，无需额外配置
- 支持 easycom 自动引入，减少 import 代码

**对应原型组件：**

| 原型元素  | uView 组件                      |
| --------- | ------------------------------- |
| 主/次按钮 | `u-button`                      |
| 开关      | `u-switch`                      |
| 底部 Tab  | `u-tabbar` 或 pages.json tabBar |
| 分段控制  | `u-subsection`                  |
| 列表项    | `u-cell` / `u-list`             |
| 标签      | `u-tag`                         |
| 弹窗/表单 | `u-popup` / `u-form`            |
| 导航栏    | `u-navbar`                      |

**安装：**

```bash
npm install uview-ui
```

**配置要点：** 见 `main.js`、`pages.json`（easycom）、`uni.scss`（主题变量）。

---

### 2.2 qiun-data-charts（图表库）

**选用原因：**

- uni-app 生态最成熟的跨端图表方案（基于 uCharts）
- 支持环形图（账单模型占比）、折线图（消耗趋势）、柱状图（月度对比）
- 不依赖 DOM Canvas，小程序端使用原生 canvas 组件
- 通过 DCloud 插件市场以 `uni_modules` 方式安装，与 HBuilderX 兼容

**安装方式（二选一）：**

1. HBuilderX → 工具 → 插件安装 → 搜索「qiun-data-charts」
2. [插件市场](https://ext.dcloud.net.cn/plugin?id=271) 下载后放入 `uni_modules/`

**不使用 ECharts 的原因：**

- ECharts 在小程序端需 renderjs 或分包，体积大、配置复杂
- qiun-data-charts 更轻量，与 uni-app 页面生命周期配合更好

---

### 2.3 luch-request（网络请求）

**选用原因：**

- 基于 `uni.request` 封装，天然跨端
- 支持请求/响应拦截器（JWT、错误码统一处理）
- 支持请求取消、重试、上传下载

**替代方案：** 自行封装 `utils/request.js`（小项目可行，本项目推荐 luch-request）。

---

### 2.4 Vuex 3（状态管理）

**选用原因：**

- Vue 2 官方推荐，uni-app 内置支持
- 管理：用户信息、月度额度、API Key 列表、全局 loading

**模块划分建议：**

```
store/
├── index.js
└── modules/
    ├── user.js      # 用户/会员
    ├── records.js   # 记账记录
    ├── apiKeys.js   # API Key
    └── stats.js     # 统计数据缓存
```

---

### 2.5 dayjs（日期）

**选用原因：**

- 仅 2KB，替代 moment.js
- 支持时区、格式化、相对时间（「今天」「昨天」）
- 纯 JS，无 DOM 依赖，全平台可用

## 3. 不推荐 / 暂缓引入

| 依赖                | 原因                                            |
| ------------------- | ----------------------------------------------- |
| Pinia               | 需 Vue 3，当前项目为 Vue 2                      |
| uView Plus          | Vue 3 专用                                      |
| ECharts             | 跨端成本高，第一版用 qiun-data-charts 足够      |
| Tailwind CSS        | uni-app 对原子化 CSS 支持差，用 SCSS 变量更合适 |
| axios               | 依赖 XMLHttpRequest，小程序不可用               |
| localStorage 封装库 | 应统一使用 `uni.setStorageSync`                 |

## 6. 平台差异处理策略

| 场景             | 方案                                                                                         |
| ---------------- | -------------------------------------------------------------------------------------------- |
| 安全区（刘海屏） | `uni.getSystemInfoSync().safeAreaInsets` + CSS `padding-bottom: env(safe-area-inset-bottom)` |
| 图表渲染         | qiun-data-charts 统一组件，内部处理平台差异                                                  |
| 文件下载/导出    | `#ifdef H5` / `#ifdef APP-PLUS` / `#ifdef MP-WEIXIN` 条件编译                                |
| 登录             | 微信：`uni.login`；App：手机号；H5：扫码/账号                                                |
| 存储敏感数据     | Key 仅存服务端；本地只缓存非敏感配置                                                         |
