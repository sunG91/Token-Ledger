# Token随手记 — 跨端代码规范

> 版本：v1.0  
> 更新日期：2026-06-06  
> 适用平台：**Android · iOS · 微信小程序 · H5(Web)**  
> 强制执行：ESLint + Prettier + Stylelint + Husky pre-commit

---

## 1. 总则

1. **一套代码，四端运行** — 禁止为单平台写死逻辑，差异必须用条件编译隔离。
2. **uni API 优先** — 网络、存储、导航、弹窗一律走 `uni.*`，不直接用浏览器或原生 API。
3. **提交前必过检** — 执行 `npm run check`，零 error 方可提交。
4. **AI 改码后必检** — Cursor Agent 每次修改代码后须运行 `npm run check`（见 `.cursor/rules/`）。

## 2. 条件编译规范

### 2.1 语法

```javascript
// #ifdef APP-PLUS
// 仅 Android / iOS App
// #endif

// #ifdef MP-WEIXIN
// 仅微信小程序
// #endif

// #ifdef H5
// 仅 Web
// #endif

// #ifndef H5
// 除 H5 外的所有平台
// #endif
```

### 2.2 使用原则

| 场景               | 写法                                               |
| ------------------ | -------------------------------------------------- |
| 平台特有 API       | 必须用 `#ifdef` 包裹                               |
| 样式差异（安全区） | 在 `<style>` 内使用条件编译                        |
| 可统一的逻辑       | **不要** 条件编译，保持单一代码路径                |
| 文件级差异         | 使用 `.vue` + `.nvue` 或 `xxx.h5.js` / `xxx.mp.js` |

### 2.3 禁止事项

```javascript
// ❌ 禁止：运行时判断平台后调用 DOM
if (uni.getSystemInfoSync().platform === 'web') {
  document.querySelector('.btn').click();
}

// ✅ 正确：编译期隔离
// #ifdef H5
document.querySelector('.btn').click();
// #endif
```

## 3. Vue 组件规范

### 3.1 文件结构

```vue
<template>
  <view class="summary-card">
    <!-- 内容 -->
  </view>
</template>

<script>
  export default {
    name: 'SummaryCard',
    props: {
      title: { type: String, required: true },
      tokenCount: { type: Number, default: 0 },
    },
    data() {
      return {};
    },
    computed: {},
    methods: {},
  };
</script>

<style lang="scss" scoped>
  @import '@/styles/variables.scss';

  .summary-card {
    border-radius: $radius-card;
  }
</style>
```

**顺序：** `template` → `script` → `style`（ESLint 强制）

### 3.2 命名

| 类型      | 规则        | 示例                  |
| --------- | ----------- | --------------------- |
| 组件文件  | PascalCase  | `SummaryCard.vue`     |
| 组件 name | PascalCase  | `name: 'SummaryCard'` |
| 页面目录  | kebab-case  | `pages/api-keys/`     |
| props     | camelCase   | `tokenCount`          |
| 事件      | kebab-case  | `@update-value`       |
| 工具函数  | camelCase   | `formatToken.js`      |
| 常量      | UPPER_SNAKE | `MAX_PAGE_SIZE`       |

### 3.3 组件分类

```
components/
├── base/          # 无业务逻辑：AppIcon、StatusTag
├── business/      # 业务组件：SummaryCard、RecordListItem
└── charts/        # 图表封装：DonutChart、LineChart
```

## 4. 样式规范

### 4.1 单位

| 用途                 | 单位                     | 说明               |
| -------------------- | ------------------------ | ------------------ |
| 布局宽高、间距、字号 | `rpx`                    | 750 设计稿基准     |
| 1px 边框             | `1px` 或 `0.5px`         | 细线场景           |
| 安全区               | `env(safe-area-inset-*)` | 底部 Tab、悬浮按钮 |

```scss
// ❌ 禁止在布局中使用 px（除 1px 边框）
.card {
  width: 343px;
}

// ✅ 使用 rpx
.card {
  width: 686rpx;
}
```

### 4.2 设计 Token（必须使用变量）

```scss
// styles/variables.scss — 对齐 UI 原型
$color-primary: #6c5ce7; // 紫色主色
$color-secondary: #0984e3; // 蓝色按钮
$color-bg-page: #f8f9fe; // 页面背景
$color-bg-card: #ffffff; // 卡片背景
$color-text-primary: #2d3436;
$color-text-secondary: #636e72;
$color-success: #00b894;
$color-warning: #fdcb6e;
$color-danger: #d63031;
$radius-card: 32rpx; // 16px
$radius-button: 16rpx; // 8px
$shadow-card: 0 4rpx 24rpx rgba(108, 92, 231, 0.08);
```

### 4.3 布局

- 统一使用 **Flexbox**，避免 `float`
- 列表用 `scroll-view` 或分页，避免一次渲染 1000+ 节点
- 图片指定 `mode`（`aspectFill` / `aspectFit`）

### 4.4 SCSS 导入（重要）

uni-app 中 **禁止** 使用 `@import url('...')` 引入 scss 变量文件，必须用：

```scss
@import 'uview-ui/theme.scss';
@import '@/styles/variables.scss';
```

`stylelint --fix` 曾会把 `@import` 自动改成 `url()` 导致编译失败，已在 `.stylelintrc.cjs` 关闭 `import-notation` 规则。页面内无需重复 `@import variables`，`uni.scss` 会自动注入。

### 4.5 禁止

- 不使用 `*` 通配选择器（小程序性能差）
- 不在全局污染标签选择器（除 `page` 基础样式）
- 不使用 `!important`（除覆盖第三方组件）

## 5. JavaScript 规范

### 5.1 API 调用

```javascript
// ❌ 禁止
fetch('/api/records');
localStorage.setItem('token', val);
window.location.href = '/login';

// ✅ 正确
import request from '@/utils/request';
request.get('/records');
uni.setStorageSync('token', val);
uni.navigateTo({ url: '/pages/login/index' });
```

### 5.2 异步处理

```javascript
// ✅ 推荐 async/await + try/catch
async loadSummary() {
  try {
    const { data } = await request.get('/dashboard/summary');
    this.summary = data;
  } catch (err) {
    uni.showToast({ title: err.message || '加载失败', icon: 'none' });
  }
}
```

### 5.3 数值与金额

- Token 数量：`Number` 或 `parseInt`，展示用 `toLocaleString()`
- 金额：后端返回 `decimal`，前端用 `Number` 并保留 2 位小数
- 禁止浮点直接累加金额（后端计算为准）

### 5.4 禁止

- `eval`、`new Function`
- `v-html` 渲染用户输入（XSS 风险）
- 在模板中写复杂逻辑（提取为 computed）

### 6.1 目录

```

├── request.js       # luch-request 实例 + 拦截器

api/
├── dashboard.js
├── records.js
├── bills.js
└── apiKeys.js
```

### 6.2 请求规范

- Base URL 放 `config/index.js`，按环境切换
- 统一响应格式：`{ code, message, data }`
- `code !== 0` 时统一 toast，401 跳转登录
- 敏感字段（API Key）禁止 `console.log`

## 12. 常见问题

**Q: 为什么禁止 document / window？**  
A: 小程序和 App 无 DOM，直接使用会导致运行时报错。ESLint 已配置 `no-restricted-globals` 拦截。

**Q: 能否用 TypeScript？**  
A: 第一版用 JavaScript 降低 HBuilderX 配置成本；第二版可迁移 Vue 3 + TS。

**Q: uView 和 uni-ui 能混用吗？**  
A: 可以，但建议以 uView 为主，避免样式冲突。
